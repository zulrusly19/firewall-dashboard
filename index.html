Dashboard Guide

  1. In Logs Explorer, click a row to view its details.
  2. Choose a case status or add notes, then select Save Investigation. Unsaved records show Not saved.
  3. Open Investigations to review saved cases. Click a row to update its status or notes.
  4. In Analytics & Graphs, click a chart item to see matching logs.
  • Frontend: HTML, CSS, and JavaScript.
  • Backend: Node.js with Express, exposing API routes for logs, analytics, and investigations.
  • Database: SQLite stores firewall records, accounts, and saved investigation notes/statuses.
  • Data flow: the browser requests records from the backend; the backend reads or updates SQLite and returns JSON.
  • Charts: Chart.js summarizes the stored synthetic records; attack labels are shown from the data, not detected by this app.
